# Upstream issue and pull-request audit

Audit date: **2026-10-29**. Sources are the complete GitHub issue/PR listings and discussion bodies retrieved for [Sidenai/sidex](https://github.com/Sidenai/sidex), together with the fetched PR branches. The working fork began at `24d55449173aa48da86cd9246f142c165d9325a7`; upstream `main` was `ad978652` at review time. Earlier fork changes were retained.

The inventory contains **73 ordinary issues** (39 open, 34 closed) and **59 pull requests** (14 open, 24 merged, 21 closed without merge). All 132 have an individual disposition: issues below, [all PRs in their own table](UPSTREAM_PULL_REQUESTS.md). The upstream state column is a snapshot, not an action performed against the original repository. No upstream issue or PR was closed by this work.

“Implemented” means a concrete code or documentation change exists, with the evidence and limitations stated here and in [Validation](VALIDATION.md). “Platform check” means the code path was repaired/checked but the original native OS/driver environment was unavailable. “Partial” is deliberately not a claim of complete compatibility. Maintenance questions, signing identities, store publication, empty bug reports, and proprietary remote protocols cannot be resolved by silently merging unrelated code.

## Decisions that preserve existing behavior

The review did not replace the fork wholesale with the large workspace/Bun rewrites, delete its AI features, copy personal VS Code extensions, weaken compatibility checks to make installation appear successful, or import a filesystem cache without demonstrated invalidation. Relevant changes were adapted into focused commits and tested against the retained architecture. The [PR table](UPSTREAM_PULL_REQUESTS.md) explains each such decision.

## Remaining acceptance work

Native Windows 10/11, macOS 12/13/current macOS, WSL, KDE/GNOME/Wayland, Fedora Atomic, and full Nix/Flatpak package launches require those environments. Package manifests have not been submitted to Winget/Homebrew/Flathub, and no signed/notarized release has been published. The optional Go 1.26 AI server build was not validated in this container.

The native extension API remains a subset of VS Code; full Claude Code/Unity/Copilot workflows and Microsoft Remote-SSH are not certified. Additional installed language packs can have their own translation gaps; complete bundled coverage applies to Russian, Simplified Chinese and Traditional Chinese against the committed source inventory. These limits are part of the delivered result, not silently marked as resolved.
